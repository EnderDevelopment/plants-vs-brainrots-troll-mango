# Troll Mango Mutation

This Roblox script is designed for the game Plants vs. Brainrots, providing players with a free big troll mango with mutation. The script gives a unique, mutated mango to each player when they join or when the script is loaded, enhancing the gameplay experience with a special item.

## Install

1. Open Roblox Studio and load your place.
2. Navigate to the ServerScriptService in the Explorer.
3. Insert the `BigTrollMangoGiver.server.lua` script into the ServerScriptService.

## Use

1. Run the game in Roblox Studio.
2. Players will receive a big troll mango with mutation in their backpack.
